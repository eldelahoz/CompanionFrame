# F6-T18 – Overlay and hotkey settings (manual, with Warframe)

Settings > Overlays & hotkeys. Everything saves on change; a refused value (duplicate or reserved hotkey) shows in red and the form rolls back.

1. **Hotkey capture**: click the "Scan reward screen" button (it reads "F8, Change"), press e.g. `Ctrl+Shift+F9` (in any app). The button shows the new combo; with Warframe in front it opens the reward overlay and the key does not reach the game. Esc or 10 s without a key keeps the old binding.
2. **Duplicate**: set "Move overlays" to the combo already used by "Scan reward screen". A red message appears and the old key stays.
3. **Enable**: untick "Arbitration overlay", finish an Arbitration run (or replay a log): no overlay. Tick it again: the next run shows it. Untick "Reward overlay" while it is open: it hides within ~250 ms.
4. **Opacity**: with an overlay visible, drag its slider; the overlay follows live (30-100 %).
5. **Reset position**: drag an overlay in move mode (F7, or "Move overlays" in Settings), click "Reset position" for it: it jumps back to the default spot without a restart.
6. **Move mode**: the "Move overlays" button shows every overlay with sample content so you can drag each one; the position is kept per game resolution.

Not in this slice: monitor choice, theme per overlay, auto-close timers, "test overlay" with a fixture payload, ONNX/OCR/DLL health.
