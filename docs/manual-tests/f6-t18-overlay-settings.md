# F6-T18 – Overlay and hotkey settings (manual, with Warframe)

Settings > Hotkeys / Overlay. Everything saves on change; a refused value (duplicate or reserved hotkey) shows in red and the form rolls back.

1. **Hotkey capture**: click "F8 · Change", press e.g. `Ctrl+Shift+F9` (in any app). The button shows the new combo; with Warframe in front it opens the reward overlay and the key does not reach the game. Esc or 10 s without a key keeps the old binding.
2. **Duplicate**: set "Overlay interaction toggle" to the combo already used by "Relic trigger hotkey". A red message appears and the old key stays.
3. **Enable**: untick "Arbitration overlay", finish an Arbitration run (or replay a log): no overlay. Tick it again: the next run shows it. Untick "Reward overlay" while it is open: it hides within ~250 ms.
4. **Opacity**: with an overlay visible, drag its slider; the overlay follows live (30-100 %).
5. **Reset position**: drag an overlay in interaction mode (F7), click "Reset position" for it: it jumps back to the default spot without a restart.
6. **Editor**: "Edit reward layout" opens the reward overlay clickable in editor mode; it is disabled while the reward overlay is switched off.

Not in this slice: monitor choice, theme per overlay, auto-close timers, "test overlay" with a fixture payload, ONNX/OCR/DLL health.
