# Tray and close behavior

1. Settings > App behavior: turn "Keep running when the window is closed" off (the default). Click the window X. The app quits, overlays included, and the tray icon disappears.
2. Turn it on. Click X. The window hides and the tray icon stays.
3. Left-click the tray icon: the main window shows; left-click again: it hides.
4. Right-click the tray icon: the menu (Show/Hide, Quit) appears in the app language; Show/Hide toggles the window, Quit exits.
5. Switch the app language (es, fr, de, zh, en) in Settings. Right-click the tray again: the labels follow without a restart.
